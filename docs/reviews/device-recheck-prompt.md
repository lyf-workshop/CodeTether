**iPad（iPad Air 11-inch M4，在 Mac 上）**

**两台都要查**，每项记"通过"，或"失败"加现象和错误：

1. **生产 Relay 的版本**：开始前确认生产 Relay 已经更新到 `e4bdd57`（看 `D:/Projects/Software/agenthub-archive/relay-deploy-e4bdd57-report.md`，或问用户）。没更新就停下来告诉用户。
2. **经 Relay 新建会话**：选只走 Relay，新建 5 次。每次电脑上恰好多一个会话，第一条消息只发一次，没有停在"结果待确认"。
3. **宽窄切换**：打开一个会话和变更面板、选中一个文件的 diff、输入框里留一段草稿。横竖屏切换、分屏改变宽度、恢复全屏，每次面板开着、选中的文件、diff 位置、草稿都在。
4. **被移除页**：在电脑上移除这台设备。首页顶部出现红色告警条，侧栏还在，说明哪台电脑移除了它，有"输入配对码"和"看其他电脑"两个操作。再用新码配一次能连上。
5. **文案**：连接检查是单独的页面，界面上找不到 Host、Node、Machine、ProductDevice、Supervisor、Relay、授权、grant、指纹这些词（Release 构建里也确认一次；Debug 构建里的诊断项除外）。
6. **原型抽查**：02-01 首页、02-02 待处理、02-04 变更、03-01 设备、03-04 项目、04-01 设置、04-04 连接检查、04-06 被移除，横屏截图对照 `docs/ux-redesign/tablet/png/` 的同编号原型，列出还剩的差异。
7. **重试明确失败**（只查平板）：如果能在真机上造出来，就验证"待确认 → 重试收到明确拒绝 → 显示原因、可以重新提交"；造不出来就写"真机未造出，靠单元测试覆盖"。

最后在电脑上移除测试设备，不留测试授权。
