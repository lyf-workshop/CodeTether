## 1. 目标

CodeTether 是 AI 编程工具的控制中心。要解决的问题：

1. 不用再开终端、cd 到文件夹、分别启动 Codex 和 Claude Code：在一个应用里选设备和项目，就能新建或继续会话。
2. 以前在命令行里开过的会话不会丢：选中项目文件夹时自动找出来，导入后接着做。
3. 一眼看出哪个会话在运行、在等批准、已完成或失败，以及它在哪台设备的哪个项目里。
4. 离开电脑时，手机能方便地和 Codex、Claude Code 对话：在已有项目里新建会话、接着回复，输入框和电脑上一样完整；需要你时推送提醒，并能安全地批准或停止。平板用来舒服地读对话、审阅改动，也能新建和回复。
5. 界面里的每个按钮都真的能用；还没做的只出现在“后续规划”页。

## 2. 用户和场景

用户是你自己：个人开发者，日常使用 AI 编程工具，有几台自己的电脑和服务器。团队和企业管理不在范围内。

| # | 场景 | 用哪一端 |
|---|---|---|
| S1 | 打开电脑，看到每台设备上的项目和进行中的会话，接着做 | 电脑 |
| S2 | 把一个文件夹添加为项目，同时导入以前在命令行里开过的会话 | 电脑 |
| S3 | 在配对的 Linux 服务器或 Mac 上的项目里开一个 Codex 会话 | 电脑 |
| S4 | 外出时手机推送“有 1 个需要批准”，点开看清楚要做什么，再批准或拒绝 | 手机 |
| S5 | 任务完成后用平板读完整对话、逐行看改动，再追加一条指令 | 平板 |
| S6 | 会话失败，看到原因和下一步，重试或换个说法 | 三端 |
| S7 | 会话跑偏了，马上停止 | 三端（只限在电脑本机上运行的 Codex 会话） |
| S8 | 在路上想到一个问题，用手机在某个项目里新建 Claude Code 会话，问完就锁屏；它做完时收到推送，回来接着聊 | 手机 |
| S9 | 电脑上开着的会话，出门后在手机上接着回复 | 手机 |

## 3. 核心概念和规则

- **账号 › 设备 › 项目 › 会话**：所有界面都按这个顺序组织。
- **账号**：邮箱登录码登录。MVP 只能登录已有账号，在应用里注册新账号以后再做（A9）。电脑端登录后才能让手机和平板访问；配对设备不需要账号。
- **设备**：能运行 AI 工具的电脑，包括“这台电脑”和用 CodeTether Node 配对的设备（Linux x64 / arm64、macOS arm64）。没有只读设备：列出来的设备都能浏览、新建会话、发送。
- **手机和平板不是设备**：它们是遥控端，登录同一账号后经过电脑访问电脑和它配对的设备；自己不运行 AI 工具，不出现在“设备”列表里。手机和平板上把电脑显示为它的名称（例如“Windows 台式机”），不显示“这台电脑”。
- **遥控端不影响电脑上的工作**：手机或平板上关闭应用、切到后台、锁屏、断网、被系统清理、退出登录、卸载，都不会停止或暂停电脑上的会话。只有点“停止”才会停止。手机回来后重新读取状态，看到的是电脑上的真实进度。
- **访问权逐台授予**：每台手机或平板要在每台电脑上用配对码配对一次。配对码只显示在电脑上，所以配对必须人在电脑前。电脑可以随时移除某台手机或平板，移除后它要用新的配对码重新配对才能再访问。移除只影响这台电脑。
- **项目**：一台设备上的一个文件夹。同一设备上的同一文件夹只能是一个项目。移除项目只取消登记，不删除文件。
- **会话**：一个 AI 工具在一个项目里的一段对话。会话不会换 AI 工具，也不会换设备。
- **AI 工具**：Codex 和 Claude Code，能力不同，界面按真实能力显示：
  - 电脑本机上的 Codex：对话、批准、停止、查看变更。
  - 配对设备上的 Codex：对话。
  - Claude Code（任何设备）：对话，只读取和搜索文件，不修改文件、不执行命令；新建时可以选推理强度。
- **只显示真实能力**：后端不支持的操作不放按钮，在原地说明原因；还没做的功能只出现在“后续规划”页。没有假开关。
- **演示数据**：明确标记；演示操作不调用真实的登录、删除和 AI 执行接口。

## 4. 功能清单

表格怎么读：

- 三端列写的是这一端在哪个阶段提供（阶段见 03 §4）：`D1` 电脑 v4 收尾，`M1` 手机查看，`M2` 手机对话和处理，`M3` 手机推送，`T1` 平板，`X1` 三端输入框增强（M2 之后），`L` 以后，`—` 这一端不做。

## 6. 非功能要求

- **安全**：遵守 03 §6 的不变量。手机和平板的设备私钥放 Android Keystore（优先 StrongBox），不导出；本地缓存只放在应用私有目录。控制权限只能由你在电脑界面上授予；配对码只在电脑上显示，5 分钟有效、只能用一次、输错 5 次作废，校验不能被重试绕过；移除后立刻断开。批准、停止前先解锁手机（A7）。批准、停止这类操作不能因为重连或重试被执行两次。
- **隐私**：系统通知和推送只写类型、设备 · 项目和一句说明，不含会话标题、提示词、命令和路径；锁屏上只显示类型和数量。推送经手机和电脑之间的加密连接送达，不经过第三方推送服务。
- **文案**：界面只用中文；Codex、Claude Code、Relay、Node 保留英文；统一用“设备、项目、会话、等待批准、AI 工具”；错误信息写原因和下一步，不直接显示错误码（技术详情可展开）。
- **外观**：浅色和深色都完整；电脑默认浅色，手机和平板跟随系统。
- **无障碍**：电脑全部操作可以用键盘完成，焦点清晰；文字对比度达到 AA；状态不只靠颜色区分。手机和平板支持 TalkBack、系统字体放大，可点区域不小于 48dp。完整的 WCAG 验证需要用辅助技术手动测试和专业评审。
- **性能（建议值，要在真机上确认）**：电脑冷启动到“设备”页 3 秒内；手机从点开通知到看到会话 2 秒内（网络正常）；长对话滚动不卡顿。
- **可靠**：发送、新建都带操作编号，重试不会重复执行；断线时只读显示最后的状态并标明“未连接”，不排队发送。
- **平台**：电脑 Windows 和 macOS；手机和平板 Android 10 及以上，按最新版本适配。vivo（OriginOS）、小米（HyperOS）、OPPO（ColorOS）、荣耀都是 Android，可以安装；华为 HarmonyOS 4 及以前可以安装 APK，HarmonyOS 5 / NEXT 不能。先直接安装 APK，不上架应用商店。iOS 和 iPadOS 以后。
- **发布**：你验收新版本之前，已安装的 Mac 和 Windows 版本保持不变。编码智能体不部署、不推送、不替换已安装的版本。

## 7. 不做

- 团队、企业管理、计费、多用户共享。
- 会话中途换 AI 工具或换设备。
- 一个项目对应多台设备或多个文件夹。
- SSH、终端、文件同步、在应用里编辑文件。
- 只读设备。
- 手机和平板自己运行 AI 工具、添加项目、配对设备、导入以前的会话、完整设置。
- 从 AI 输出的文字里猜“它在问你问题”。
- 断线时排队发送，恢复后自动补发。
- 没有付费 Apple 开发者会员时做 iOS 和 iPadOS。

## 8. 验收标准

每个阶段都要满足：

1. **只显示真实能力**：每个按钮都能用；不支持的操作没有按钮，原地有原因；没做的功能只在“后续规划”页。
2. **状态完整**：每个页面都有加载、空、出错、离线状态，且都有下一步。
3. **外观和文案**：浅色和深色都检查过；界面里没有英文句子和错误码（允许的英文名词除外）。
4. **演示数据**：有明显标记；点演示数据上的操作不会调用真实接口。
5. **键盘和读屏**：电脑全部操作可以只用键盘完成；手机和平板用 TalkBack 能完成主要流程。

按功能区：

- **访问**：没在电脑上允许时，手机和平板看不到这台电脑；没有有效配对码就配对不上；过期、用过、作废的配对码都失败并说明原因；移除后已连接的手机立刻断开，下一次请求失败并显示原因；电脑上正在运行的工作不受影响。本机其他程序不能绕过电脑界面授予控制权限。
- **设备和项目**：取消配对、移除项目前先检查，不能做时说明原因，不给确认按钮；同一文件夹不能添加两次。
- **以前的会话**：扫描结果默认选中可导入的；扫描结果过期（409）时自动重新扫描，保留你已经选的项。
- **发送和新建**：会话忙碌（409）时说明“正在运行，结束后再发送”；重试不会产生两条相同的消息。
- **批准和停止**：只在后端支持的会话上出现；手机上先解锁再执行；处理后待处理数量立刻更新；点通知只会打开会话，不会直接批准。
- **通知**：通知和推送内容里没有会话标题、提示词、命令和路径；锁屏上只有类型和数量。手机锁屏放置 30 分钟后，电脑上出现等待批准，手机仍能收到推送（按 O10 设置好之后；在你的手机上实测）。
- **后台和重连**：手机切到后台再回来、断网再恢复后，状态和电脑上一致，没有重复的操作。
- **遥控端不影响工作**：手机上发出一条消息后立刻强制停止应用（或断网、锁屏），电脑上的会话照常运行到结束；重新打开手机应用后看到完整的结果。
- **连接**：M0 起直连和 Relay 两种方式都要在真机上走通。
