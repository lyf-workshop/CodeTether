# CodeTether 图标（定稿：风筝）

方向 A（蓝底白色连线）用户认为太普通、配色不好看，已放弃。

新图形是一只风筝和一根线：AI 工具在别的设备上干活，线一直在你手里，对应名字里的 Tether。线尾的圆点是你手里的这一头。

配色：
- 底色深青，`#165566` 渐变到 `#0a2731`，风筝后面有一层很淡的青色光晕。
- 风筝四片，暖色从亮到暗：`#ffd38f`、`#ffb347`、`#ff9457`、`#f2643f`，整体右倾 14 度。
- 线和圆点米白 `#f4efe6`，不用纯白，和暖色更协调。

深底暖色在浅色和深色任务栏上都和背景拉得开，也和常见的蓝色开发工具图标区分得开。界面里的 `--ct-accent` 蓝色不变，图标不用跟它一致。

| 文件 | 用途 |
|---|---|
| `codetether-app.svg` | 主图，铺满。Windows 的 48、64、128、256 像素和其他 PNG |
| `codetether-app-small.svg` | 16、24、32 像素专用：风筝摆正，只留左黄右红两片，线改直、加粗，圆点放大 |
| `codetether-app-macos.svg` | macOS：图形 824 像素居中，四周透明留边 100 像素 |

16 像素时，按 Chromium 渲染的像素检查，能看出黄红两半的菱形和左下的白线圆点。真实任务栏和托盘的样子要在安装后截图确认。

Windows 托盘用的是应用图标里的 16 像素那一层，所以小尺寸版本也决定托盘的样子。macOS 菜单栏的单色模板图标以后再做（要改原生代码并在 Mac 上验证）。
